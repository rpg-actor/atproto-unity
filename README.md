# AT Protocol Unity Toolkit

This is an experimental work-in-progress toolkit for AT Protocol functionality in Unity.

Included Features
- OAuth and Password sign-in for desktop or WebGL
- Declaring and requesting login scope permissions
- Reading repository data including RPG.ACTOR expected records
- Creating, updating, and deleting records on user PDS
- Composing and validating Lexicon records in Unity.
- Search and fill composition for lexicon records.

The repository also includes the separate RPG.Actor package for character sprites and a demo scene.
